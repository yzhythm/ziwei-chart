================================

本目录里的 4 个文件就是全部要上传的东西，**不用管文件夹结构，四个文件平铺拖进 GitHub 上传框即可**。

文件清单
--------

| 文件 | 大小 | 说明 |
|---|---|---|

为什么文件名是英文的
--------------------

GitHub 上传框不支持拖拽文件夹的目录结构（拖进去会全部平铺到仓库根目录）。
所以我把整个网站打包成了**两个独立的单文件**——index.html 自己带全部 CSS/JS/图标，
share.html 也一样。这样你在网页上传框里一次拖四个文件，GitHub 上就是根目录四个文件，
Pages 直接就能跑，**一行都不用改**。

上传步骤
--------

1. 打开你仓库的 **Add file → Upload files** 页面
2. 把本目录下的 4 个文件**全部选中**，拖进那个虚线框（或点 "choose your files" 逐个选）
3. 页面下方会列出 4 个文件，填一个 commit 说明（比如 `feat: 紫微斗数在线排盘 v1.0`）
4. 点 **Commit changes**

开启 Pages
----------

1. 仓库 → **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 **main**（或你用的分支名），目录选 **/ (root)**
4. **Save**，等 1–2 分钟

地址格式是：`https://<你的用户名>.github.io/ziwei-chart/`

⚠ 自定义域名那个框要留空
--------------------------------

如果你在 Pages 设置里看到「自定义域名 / Custom domain」输入框，**把它清空，不要填
`zyhythm.github.io/ziwei-chart/`**。

那个框只接受「你自己买的主机名」（如 example.com、www.example.com、blog.example.com），
它不接受带路径的地址，也不接受 GitHub 自己分配的 github.io 地址。填了会报：

    自定义域名 "<zyhythm>.github.io/ziwei-chart/" 格式不正确。

清空即可。GitHub 会自动用默认地址 `https://zyhythm.github.io/ziwei-chart/` 托管，
不需要任何 DNS 配置。

想让地址短一点、不带 `/ziwei-chart/` 后缀？那要把仓库改名为 `zyhythm.github.io`
（Settings → General → Repository name）。但一个账号只能有一个这种根站点，
如果你以后想放别的内容在根路径上，就别改。

验证
----

打开上面那个地址，确认这几点：

- 左侧九项菜单可点
- 点「开始排盘」能出十二宫命盘
- 「紫微解读」出十二卷报告，卷八是「钦天取用神」，含左右昌曲专章
- 「运限分析」出 84 根 K 线，鼠标悬停有明细
- 右上角语言能切 简体中文 / 繁體中文 / English（英文态卷八标题应为罗马数字编号）
- 「双人排盘」能出合盘报告
- 「同类型命盘」能出结构指纹与同年同构结果

把二维码改成指向你的域名
------------------------

分享页里的二维码目前指向的是临时部署地址。拿到你的 Pages 地址后，在项目根目录执行：

```
python _calc/rebuild_for_github.py https://<你的用户名>.github.io/ziwei-chart/
```

脚本会重出分享页、两张纯二维码、两张水墨分享卡和分享包 zip，并逐张解码验证内容。

也可以完全不动脚本——分享页里直接粘贴你的地址，二维码会即时重算，支持下载 PNG / SVG / 水墨卡。
